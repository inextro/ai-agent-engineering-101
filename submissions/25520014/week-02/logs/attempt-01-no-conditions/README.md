# attempt-01 — 실험 조건 기록이 빠진 첫 6런

내용과 결론은 attempt-02(상위 `results.csv`)와 같다. 옮긴 이유는 하나다.
lab 4번이 "실행마다 프롬프트, 도구 집합, max_steps 같은 실험 조건을 기록한다"고
요구하는데, 이 6런의 로그에는 그 조건 블록이 없다. 조건은 REPORT.md에 한 번만
적혀 있었다.

`run_ab.py`가 각 로그 첫머리에 조건 전문(모델, claude -p 플래그, 도구 집합,
IRREVERSIBLE, 상한값, task/expected, 시스템 프롬프트 전문)을 찍도록 고친 뒤
같은 조건으로 다시 6런을 돌렸다. 하네스 코드와 상한은 건드리지 않았다.

이 디렉토리는 지우지 않는다. 과정 기록이다.
